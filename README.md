# Assignment 1 (student)
*Description

This project demonstrates basic Object-Oriented Programming (OOP) concepts in Java using a Student class. The program stores student marks for three subjects, calculates the percentage, and determines whether the student has passed or failed (minimum 35%).

*It showcases:

Classes & Objects

Constructors

Methods (with return values & parameters)

Encapsulation (private data members + getters)

 *Features

Stores student name and marks

Calculates percentage

Displays Pass/Fail result

Uses encapsulation for data protection

# Assignment 2 (employee)

*Description

This project demonstrates Object-Oriented Programming (OOP) concepts in Java using an Employee base class and derived classes FullTimeEmployee, InternEmployee, and TraineeIntern.

The program calculates salary hikes based on employee type:

Full-Time Employee → 50% hike

Intern Employee → 25% hike

It also displays salary before and after increment and demonstrates constructor calls and destructor behavior.

*Concepts Demonstrated

 Single Inheritance

 Hierarchical Inheritance

 Multilevel Inheritance

 Constructors (Base & Derived classes)

 Method Overriding

 Polymorphism

 Destructor equivalent (finalize() method)

*Features

Base class for common employee details

Different salary hike calculations

Constructor chaining using super()

Destructor demonstration using finalize()

Object creation and garbage collection demo
